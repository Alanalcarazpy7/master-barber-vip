# Master Barber VIP Landing

Demo estática lista para Vercel con el formato:

- `index.html`
- `data.js`
- `styles.css`
- `assets/`
- `vercel.json`

## Probar localmente

```bash
npx serve .
```

## Deploy en Vercel

```bash
vercel --prod
```

Las imágenes principales usan URLs reales del sitio oficial y tienen fallback local armado desde las capturas compartidas para que la demo no quede vacía si una imagen externa falla.
